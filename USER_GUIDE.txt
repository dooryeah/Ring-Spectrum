Ring Spectrum - 环形音乐频谱

启动与退出：
- 双击 RingSpectrum.exe 启动。
- 鼠标右键点击频谱中心圆盘，或者按 ESC 键退出程序。

调整参数与热键：
- 移动窗口：鼠标左键按住中心圆盘拖拽，或使用热键 上下左右方向键
- 调整大小：Ctrl + ↑ / Ctrl + ↓
- 调整透明度：Ctrl + [ / Ctrl + ]
- 调整敏感度：+ / -
- 更改颜色：C (切换预设), Shift + C (随机生成)
- 增减柱子数量：N / M
- 衰减速度：A / S (A变平滑, S变灵敏)

配置文件：
参数会自动保存在程序同目录下的 config.json 中。
