Ring Spectrum - 环形音乐频谱
当前版本：v0.4.0

启动与交互：
- 正式发布包建议从 GitHub Releases 下载；源码仓库保留代码和文档，exe / zip 发布产物放在 Release 附件中。
- 双击 RingSpectrum.exe 启动程序。
- 程序启动后不会出现任何主窗口或任务栏图标，而是在系统托盘区（右下角）出现一个青色圆形小图标。
- 【右键点击托盘图标】，在弹出的菜单中选择“设置”打开调参窗口，在该窗口中，选择“保存配置”则保存配置于 config.json 中，点击“关闭面板”则关闭当前设置窗口。
- 【右键点击托盘图标】，在弹出的菜单中选择“预设”，可以直接点击已保存的预设名称一键切换当前视觉配置。
- 【右键点击托盘图标】，在弹出的菜单中选择“性能”，可以在“省电 / 均衡 / 高质量”之间切换运行档位。
- 【右键点击托盘图标】，在弹出的菜单中选择“退出”则可以完全退出程序。
- 频谱窗口本身（彩色的条形柱区域）为鼠标穿透，不会影响您对底层桌面或其他窗口的点击操作。

独立设置面板：
- 所有参数均在设置面板中调节。
- **预设**：在设置面板中输入预设名称后，可将当前参数保存/覆盖为一套预设；之后可在托盘菜单“预设”中一键切换。设置面板还支持复制、重命名、删除、导入和导出预设。
- **性能档位**：托盘菜单“性能”可切换省电、均衡、高质量；省电和均衡会运行时限制 FPS、根部渐隐分段数和最大柱子数，高质量最高 120 FPS。该档位独立于视觉预设，不会覆盖用户保存的柱子数量。
- **锚定缩放**：修改窗口大小时，频谱中心点在屏幕上的位置将保持不动。
- **频谱位置**：可以通过手动修改 X / Y 坐标来移动频谱中心点位置。
- **屏幕对齐**：可选择靠左、靠右、靠上、靠下、X轴居中、Y轴居中，按当前显示器紧凑对齐频谱。
- **频谱样式**：可在设置面板中选择“条状”或“环状”。
- **sp模式**：默认为 normal；切换为 beat 后，会根据低频鼓点触发短暂扩张、亮度脉冲和更长拖尾。
- **首尾渐变**：沿频谱柱排列顺序渐变；环状模式会自动做首尾衔接，避免圆环接缝处颜色突变。
- **上下渐变**：以频谱柱根部为起始颜色，沿柱子伸展方向逐渐过渡到结束颜色；条状按上下或左右方向渐变，环状按径向渐变。
- **频谱翻转**：环状在内外方向间切换（默认外翻），条状在上下方向间切换。
- **旋转90°**：可将当前频谱顺时针旋转90°。
- **根部渐隐**：开启后频谱柱只改变透明度，不改变颜色；透明度按二次曲线从根部向外递增，根部隐形，外端更清晰。
- **衰减速度**：可在 0.01 到 0.99 之间调节，数值越低回落越快，越高拖尾越长。
- **条形高度 / 条形长度**：仅在条状模式下显示，条形高度可在 10% 到 200% 之间缩放柱子实时伸展高度，条形长度按比例缩放整排条形占用范围。
- **开机自启**：暂不支持，可以把程序快捷方式放入 Windows 启动目录。
- 点击“保存配置”将配置落盘，否则退出程序时也会自动保存。

配置文件：
所有调整和自定义预设会保存在程序同目录下的 config.json 中。

发布文件：
- RingSpectrum_v0.4.0.exe 为可独立下载的当前版本程序。
- RingSpectrum_v0.4.0_Delivery.zip 为当前版本发布包，包含 RingSpectrum.exe、config.json、USER_GUIDE.txt 和 CHANGELOG.txt。
- CHANGELOG.txt 记录各版本主要变化。
