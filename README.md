> 本文件用于指导 AI Agent 完成一个**可直接运行的环形音乐频谱桌面程序**，并以 **EXE 可执行文件**形式交付。用户无需安装 Python 环境，通过 EXE 即可启动程序，并能在运行时**热修改**所有显示参数（大小、位置、透明度、敏感度、颜色等）。

   - 双击即可运行，无需任何依赖  
   - 支持**实时热修改配置**（见下文）

2. **一个简洁的用户说明文件** `USER_GUIDE.txt`，内容包括：  
   - 如何启动/退出程序  
   - 热键列表（用于调整参数）  
   - 配置文件位置（若有）

3. **源码文件夹**，但用户只需 EXE 即可使用。

## 二、程序功能需求

### 核心功能
- 实时捕获系统音频（默认麦克风，可选项立体声混音）
- 将音频转换为**环形频谱图**：柱状条围绕圆心向外辐射，随音乐跳动
- 窗口无边框、背景透明、置顶显示（类似桌面挂件）

### 热修改配置（运行时实时生效，无需重启程序）
用户可通过以下方式修改参数：

| 参数 | 说明 | 调整方式（示例） |
|------|------|------------------|
| 窗口大小 | 宽度/高度（像素） | 鼠标拖拽窗口边缘 或 热键 `Ctrl+↑/↓` |
| 窗口位置 | 屏幕 X/Y 坐标 | 鼠标拖拽窗口主体 或 热键方向键移动 |
| 透明度 | 0~100% | 热键 `Ctrl+[` / `Ctrl+]` |
| 敏感度 | 频谱响应幅度 | 热键 `+` / `-` |
| 起始颜色 / 结束颜色 | 环形渐变两端 | 热键 `C` 循环预设色板，或 `Shift+C` 随机生成 |
| 柱子数量 | 视觉密度 | 热键 `N` / `M` 增减 |
| 衰减速度 | 峰值回落平滑度 | 热键 `A` / `S` |

所有修改**立即显示**，且退出程序时可选择保存到配置文件，下次启动沿用。

### 非功能需求
- 帧率稳定在 30~60 fps，CPU 占用 < 15%（主流配置）
- 内存占用 < 200 MB
- 支持 Windows 10/11

## 三、技术约束（供 Agent 选择实现方式）

Agent 应使用以下技术栈（或等效替代）以确保打包为独立 EXE：

- **音频捕获**：`pyaudio` 或 `sounddevice`  
- **FFT 处理**：`numpy`  
- **图形界面**：`pygame` 或 `tkinter` + `matplotlib`（前者性能更佳）  
- **窗口透明/置顶**：调用 Windows API（如 `SetLayeredWindowAttributes`）  
- **热键监听**：`keyboard` 库或 `pygame` 自带事件  
- **配置持久化**：JSON 或 INI 文件，运行时读写  
- **打包工具**：PyInstaller（单文件模式，需包含所有依赖）

> 注意：需处理 `pyaudio` 的 PortAudio DLL 依赖，确保打包后能正常工作。

---

## 四、工作流（Agent 执行步骤）

1. **环境准备**  
   - 创建 Python 虚拟环境  
   - 安装依赖：`pygame`, `numpy`, `pyaudio`, `pyinstaller`

2. **实现音频处理模块**  
   - 打开音频流，每帧读取 PCM 数据  
   - 执行 FFT 并映射到指定数量的频带  
   - 提供可调节的敏感度系数

3. **实现环形图形渲染**  
   - 创建透明无边框窗口  
   - 根据频谱幅度动态绘制径向柱状条  
   - 支持窗口大小/位置动态调整（需刷新绘图坐标系）  
   - 支持全局透明度及颜色渐变

4. **实现热修改配置系统**  
   - 定义热键与参数的对应关系  
   - 实时更新渲染参数（不重启）  
   - 退出时自动保存至配置文件

5. **测试与调优**  
   - 测试不同音频输入设备  
   - 调整平滑算法避免闪烁  
   - 确保高帧率下绘图不卡顿

6. **打包为 EXE**  
   - 使用 PyInstaller 生成单文件可执行程序  
   - 在干净的虚拟机中验证可运行
