# Ring Spectrum – 环形音乐频谱桌面程序（托盘版 + 独立调参窗口）

> 本任务说明供 AI Agent 使用：在之前环形频谱程序的基础上，增加**系统托盘图标**、**独立调参窗口**、**圆心锚定缩放**，并修复配置持久化问题。最终交付一个可运行的 EXE，用户通过托盘图标右键菜单控制程序。

---

## 一、最终交付物要求

- 单个可执行文件 `RingSpectrum.exe`（Windows 平台）
- 用户说明 `USER_GUIDE.txt`（简要说明托盘图标操作、调参窗口用法）
- 配置文件（自动生成，默认与 EXE 同目录）

程序启动后**不显示任何主窗口**，只在系统托盘中显示一个图标。所有交互通过托盘图标完成。

---

## 二、功能需求（相对之前版本的修改）

### 2.1 程序入口与托盘行为
- 程序启动后**无主窗口**，只在系统托盘区显示图标（建议自定义图标或默认 pygame 图标）
- 鼠标**右键点击托盘图标**，弹出菜单，包含：
  - **设置** → 打开调参窗口
  - **退出** → 完全关闭程序
- 左键点击托盘图标可无操作或显示提示信息。

### 2.2 独立调参窗口（替代全局热键）
- 调参窗口为一个单独的 GUI 窗口（使用 `tkinter` 或 `pygame` 自带界面），包含以下控件：

| 参数 | 控件类型 | 范围/说明 |
|------|----------|------------|
| 窗口大小（宽/高） | 滑块或输入框 | 100~1000 像素，实时改变频谱窗口尺寸 |
| 频谱位置 X / Y | 滑块或步进按钮 | 相对于屏幕左上角的偏移量（像素） |
| 透明度 | 滑块 | 0~100% |
| 敏感度 | 滑块 | 0.5~5.0 |
| 起始颜色 / 结束颜色 | 颜色选择器或预设按钮 | 支持十六进制或 RGB |
| 柱子数量 | 滑块 | 20~120 |
| 衰减速度 | 滑块 | 0.1~0.9 |
| **保存**按钮 | 保存当前配置到文件 | 下次启动自动加载 |
| **关闭**按钮 | 仅关闭调参窗口，频谱继续运行 | - |

- 调参窗口**可重复打开**（多次右键菜单不会重复创建窗口，而是将已存在的窗口前置）。
- 所有参数的修改**立即生效**（频谱窗口实时响应），无需重启程序。

### 2.3 频谱窗口特性修改
- **背景**：完全透明、无边框、置顶。
- **缩放中心点**：固定为圆心。调整窗口大小时，圆心的屏幕位置保持不变，半径按比例缩放。
  - 例如：窗口从 600×600 变为 400×400，圆心相对于窗口左上角的位置不变（仍为 200,200），但实际屏幕坐标中圆心位置会随窗口整体移动，因此需要配合“频谱位置”参数来重新定位圆心。
  - 更精确说明：频谱窗口本身是一个矩形，圆形的圆心位于窗口矩形内的固定相对位置（例如宽的一半、高的一半）。当窗口大小变化时，圆心在窗口内的相对坐标不变；但为了调整圆心在屏幕上的绝对位置，用户通过“频谱位置 X/Y”来移动整个窗口的位置。
  - 实现要求：调整窗口大小后，圆心相对于窗口左上角的偏移量保持为 (width/2, height/2)，这样“频谱位置”就是窗口左上角的屏幕坐标，用户修改该坐标即可移动圆心的屏幕位置。

### 2.4 配置持久化修复
- 程序启动时，必须读取上次保存的配置文件（如 `config.json`）。
- 若配置文件不存在，则使用内置默认值。
- 用户通过调参窗口点击“保存”时，将当前所有参数写入配置文件。
- 退出程序时（通过托盘菜单退出），应自动保存当前参数，确保下次启动时完全恢复上次状态。
- **注意**：之前版本可能存在参数未正确保存或加载的 bug，必须确保：
  - 所有自定义参数（包括窗口位置、大小、透明度、敏感度、颜色等）均被序列化/反序列化正确。
  - 数据类型转换无误（例如颜色十六进制与 RGB 互转）。

## 三、技术实现要点（供 Agent 参考，不输出代码）

| 模块 | 推荐方案 | 注意事项 |
|------|----------|----------|
| 系统托盘 | `pystray` + `PIL`（或 `tkinter` 自带托盘，但功能弱） | `pystray` 需要 `pillow`，需一同打包 |
| 圆心锚定缩放 | 每次窗口大小改变后，重新计算圆心在窗口内的相对坐标，并保持圆心屏幕位置不变（通过移动窗口左上角补偿） | 公式：新窗口左上角位置 = 旧圆心屏幕坐标 - (新窗口宽/2, 新窗口高/2) |

---

## 四、用户交互流程

1. 用户双击 `RingSpectrum.exe` → 程序启动，无任何窗口，系统托盘出现图标。
2. 右键托盘图标 → 选择“设置” → 弹出调参窗口。
3. 在调参窗口中：
   - 调整“频谱位置 X/Y” → 频谱窗口整体移动，圆心位置改变。
   - 调整“窗口大小” → 频谱窗口立即缩放，圆心保持在窗口中心，屏幕位置不变。
   - 调整其他参数（敏感度、颜色等） → 频谱显示实时变化。
   - 点击“保存” → 参数保存到配置文件。
   - 点击“关闭” → 调参窗口隐藏，频谱继续运行。
4. 右键托盘图标 → 选择“退出” → 程序自动保存参数并退出。
